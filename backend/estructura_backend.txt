## Notas de Organización

### Módulos Core (Implementación Obligatoria)
1. **MÓDULO 1 - PARSING**: Parser de pseudocódigo + AST
2. **MÓDULO 2 - ANÁLISIS**: Análisis de complejidad (O, Ω, Θ)
3. **MÓDULO 3 - PATRONES**: Detección de patrones algorítmicos
4. **MÓDULO 4 - VISUALIZACIÓN**: Generación de árboles y diagramas
5. **MÓDULO 5 - SERVICIOS**: Orquestación y lógica de negocio
6. **MÓDULO 6 - INFRAESTRUCTURA**: DB, LLMs, exportación

### Módulos Opcionales (Bonus/Mejoras)
- **Sistema Multiagente** (LangGraph): `infrastructure/agents/`
- **Profiling**: `app/profiling/`
- **Generador de Datasets**: `dataset_generator/`

### Bases de Datos
- **MongoDB**: Almacenamiento principal de algoritmos y análisis (flexible schema)
- **PostgreSQL**: Alternativa para datos relacionales (opcional, usar una u otra)
- **Redis**: Caché de resultados de análisis (opcional pero recomendado)

### Orden de Implementación Recomendado
1. Configuración inicial + estructura proyecto
2. Parser (gramática + AST)
3. Análisis de complejidad básico (loops simples)
4. Detección de patrones básicos
5. Integración LLMs (Claude + Gemini)
6. Análisis avanzado (recursión, recurrencia)
7. Visualización
8. Exportación
9. Testing completo
10. Optimización + profiling
